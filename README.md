# erdetøltid.dk

Er det øltid? Ja.

En statisk side på [erdetøltid.dk](https://erdetøltid.dk/), hostet på GitHub Pages fra `master`.

- `index.html`: hele sitet. Svaret vokser til det fylder skærmen, og Del-knappen bruger browserens delemenu (fallback: kopiér link eller del på Facebook).
- `og.png`: billedet der vises når linket deles. Det stiller kun spørgsmålet.
- `CNAME`: domænet i punycode (`xn--erdetltid-p8a.dk`). GitHub Pages læser det herfra.

Et push til `master` er et deploy. Der er ingen build, ingen afhængigheder og intet dynamisk.
